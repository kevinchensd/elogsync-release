# 一录清个人版下载 / ELogSync Personal downloads

## 简体中文

这里是一录清个人版的公开下载安装与版本说明入口。

- [一录清个人版](docs/personal/README.md)

安装程序只作为 GitHub Release assets 提供。请在 Personal Release 页面查看安装说明、校验值和版本变化。

请在 [Releases](https://github.com/kevinchensd/elogsync-release/releases) 选择需要的 Personal 版本下载。

- 个人版：`personal-v<版本号>`
每个 Personal Release 页面都提供支持的平台安装器、SHA-256 校验值以及中英双语发布说明。

## English

This release branch is the public download and release-notes entry for ELogSync Personal.

- [ELogSync Personal](docs/personal/README.md)

Installers are available only as GitHub Release assets. Use each Personal Release page for installation guidance, checksums, and version changes.

Use [Releases](https://github.com/kevinchensd/elogsync-release/releases) to download a specific Personal version.

- Personal: `personal-v<version>`
Each Personal release page contains its supported installers, SHA-256 checksums, and bilingual release notes.
