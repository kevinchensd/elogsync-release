# ELogSync Personal v0.1.15

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.15-windows-x64-setup.exe`
- **SHA-256**: `14B8CB967DE37E583ED32084A7A807C9AC6BFD7B1F4FCC8E12C25DB3B282D4C5`
- The installer uses per-user installation and does not require administrator privileges. Close ELogSync before installing or upgrading.

### Highlights

- Fixed quotation form behaviour so date pickers and other editable controls are selected by stable field identities rather than translated labels. Supplier and customer quote dates remain editable in both English and Simplified Chinese.
- Fixed English-language confirmation text in Backup & Restore and improved language selection so the settings page lists only currently supported interface languages with their native names and locale codes.
- Improved the Receivables and Receipts list creation actions while preserving existing workflows and business data.

### Data and limitations

- **Local data format version: 76**, unchanged from v0.1.14; no database schema upgrade is performed. Version 76 installations can upgrade directly.
- Existing business records, backup files, attachments, user input, and local configuration remain unchanged.
- Only a Windows x64 NSIS installer is provided; MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.15-windows-x64-setup.exe`
- **SHA-256**：`14B8CB967DE37E583ED32084A7A807C9AC6BFD7B1F4FCC8E12C25DB3B282D4C5`
- 安装器采用当前用户模式，不要求管理员权限。安装或升级前请关闭正在运行的一录清。

### 本版内容

- 修复报价表单行为：日期选择器和其他可编辑控件改由稳定字段身份决定，不再依赖已翻译的标签文字。供应商报价和客户报价日期在英文、简体中文界面均可正常编辑。
- 修复备份与恢复的英文确认文案；优化语言选择，仅显示当前已支持的界面语言，并使用其本名和 locale 代码。
- 优化应收与到账列表的新增操作样式，保持既有流程和业务数据不变。

### 数据与限制

- **本机数据格式版本：76**，与 v0.1.14 相同，不执行数据库结构升级；数据格式为 76 的安装可直接升级。
- 本版不改变已有业务记录、备份文件、附件、用户输入或本机配置。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
