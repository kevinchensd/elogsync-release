# ELogSync Personal v0.1.12

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.12-windows-x64-setup.exe`
- **SHA-256**: `EB70DEBA571A00FAB78FA48AD4B4FCE68D28431D699FD1D5B8F77E3872E65F58`
- The installer uses per-user installation and does not require administrator privileges. Close ELogSync before installing or upgrading.

### Highlights

- Improved English and Chinese consistency across system settings, relationship workspaces, shared list controls, opportunities, quotes, fulfillments, orders, and receipts.
- Opportunity lists now use the validated quote and order list tools for search, sorting, filter confirmation, current filter tags, pagination, and export scope selection.
- Opportunity XLSX exports contain readable business fields and linked customer/contact names instead of internal IDs. Column headings, statuses, and purchase stages follow the current interface language.
- Quick Note overview records open their own details directly. Adding a linked customer or supplier now saves that relationship immediately; users can remove it if it was selected by mistake.
- Fixed English AI connection feedback and aligned export confirmation actions.

### Data and limitations

- **Local data format version: 76**, unchanged from v0.1.11; no database schema upgrade is performed. Version 76 installations can upgrade directly.
- Existing business records, attachments, user input, and AI candidate text are unchanged and are never translated automatically.
- Only a Windows x64 NSIS installer is provided; MSI and macOS installers are not published.
- The unified i18n module is used for new, changed, and migrated areas. Stable historical pages may continue to use the compatibility layer until they are changed or another interface language is added.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.12-windows-x64-setup.exe`
- **SHA-256**：`EB70DEBA571A00FAB78FA48AD4B4FCE68D28431D699FD1D5B8F77E3872E65F58`
- 安装器采用当前用户模式，不要求管理员权限。安装或升级前请关闭正在运行的一录清。

### 本版内容

- 改进系统设置、业务关系工作区、共享列表控件、商机、报价、履约、订单和收款区域的中英文显示一致性。
- 商机列表接入已验证的报价和订单列表工具：搜索、排序、筛选确认、当前条件标签、分页和导出范围选择保持一致。
- 商机 XLSX 导出改为用户可读业务字段及关联客户、联系人名称，不再输出内部 ID；字段标题、状态和采购阶段随当前界面语言显示。
- 随手记概览中的记录可直接打开自身详情；选择关联客户或供应商后立即保存关系，如选择错误可手动移除。
- 修复英文 AI 连接反馈，并统一导出确认操作的对齐方式。

### 数据与限制

- **本机数据格式版本：76**，与 v0.1.11 相同，不执行数据库结构升级；数据格式为 76 的安装可直接升级。
- 本版不改变已有业务记录、附件、用户输入或 AI 候选原文，也不会自动翻译这些内容。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
- 统一 i18n 模块用于新增、修改和已迁移区域；稳定历史页面可继续使用兼容层，直到页面被修改或新增界面语言。
