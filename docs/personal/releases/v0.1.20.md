# ELogSync Personal v0.1.20

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.20-windows-x64-setup.exe`
- **SHA-256**: `14754C6874ADF249E0C9B3FA5A34599B4680173C3F35A41D11C3AAAE48EB4DE5`
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing; the installer checks the desktop process and local service before replacing files.

### Highlights

- AI organizer candidates now retain parsed customer, supplier and contact details in their corresponding formal fields.
- Customer and supplier candidates support organization phone, detailed address and website; contact candidates support mobile, office phone and email.
- Details that cannot be safely matched to a field remain in the candidate notes for review.

### Data and limitations

- **Local data format version: 89. Database schema upgrade: Yes.** The installer accepts direct upgrade only from format 87, including v0.1.19 installations.
- If the installed data format is 76, install v0.1.18 first, then install v0.1.20. Do not skip a release marked as having a database schema upgrade.
- Application-version gaps do not matter when the data format is unchanged. Existing records, attachments, user input and local configuration are preserved.
- Only a Windows x64 NSIS installer is provided. MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.20-windows-x64-setup.exe`
- **SHA-256**：`14754C6874ADF249E0C9B3FA5A34599B4680173C3F35A41D11C3AAAE48EB4DE5`
- 安装器为当前用户模式 Windows x64 NSIS 安装包。安装前请关闭一录清；安装器会在替换文件前检查桌面主程序和本机服务。

### 本版内容

- AI 整理候选现在会把已识别的客户、供应商和联系人资料写入对应正式字段。
- 客户和供应商候选支持单位电话、详细地址和网站；联系人候选支持手机、办公电话和邮箱。
- 无法安全对应字段的内容仍保留在候选说明中，供用户审核。

### 数据与限制

- **本机数据格式版本：89，数据库结构升级：有。** 安装器仅允许从格式 87 直接升级，包括已安装 v0.1.19 的情况。
- 如果当前数据格式为 76，请先安装 v0.1.18，再安装 v0.1.20；不得跳过标注“有数据库结构升级”的历史发布版本。
- 应用版本号不连续但数据格式未变化时可以直接跨版本升级。已有业务记录、附件、用户输入和本机配置会被保留。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
