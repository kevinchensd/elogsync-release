# ELogSync Personal v0.1.13

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.13-windows-x64-setup.exe`
- **SHA-256**: `7FCA7A61815490C433A254FAA877F912F2DFED1354F4ADC56309926449E74BE2`
- The installer uses per-user installation and does not require administrator privileges. When upgrading, it restores the registered installation folder. Close ELogSync before installing; if its local service is still running, the installer asks to close it before replacing files.

### Highlights

- Fixed Windows in-place upgrades when `elogsync-server.exe` remains running after the desktop window closes.
- The installer now checks both the desktop application and its local Go service before installation or uninstallation, then uses its own confirmation flow to stop a running process before replacing files.
- This prevents incomplete upgrades caused by skipping a locked server executable.

### Data and limitations

- **Local data format version: 76**, unchanged from v0.1.12; no database schema upgrade is performed. Version 76 installations can upgrade directly.
- Existing business records, attachments, user input, AI candidate text, and local configuration remain unchanged.
- Only a Windows x64 NSIS installer is provided; MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.13-windows-x64-setup.exe`
- **SHA-256**：`7FCA7A61815490C433A254FAA877F912F2DFED1354F4ADC56309926449E74BE2`
- 安装器采用当前用户模式，不要求管理员权限。升级时会恢复已登记的安装目录。安装前请关闭一录清；如果本机服务仍在运行，安装器会先请求关闭它，再替换文件。

### 本版内容

- 修复桌面窗口关闭后 `elogsync-server.exe` 仍在运行时，Windows 原地升级无法覆盖文件的问题。
- 安装或卸载前，安装器现在同时检查桌面主程序和本机 Go 服务；发现进程仍在运行时，使用自身确认流程停止进程后再替换文件。
- 不再允许跳过被锁定的服务程序文件而完成不完整升级。

### 数据与限制

- **本机数据格式版本：76**，与 v0.1.12 相同，不执行数据库结构升级；数据格式为 76 的安装可直接升级。
- 本版不改变已有业务记录、附件、用户输入、AI 候选原文或本机配置。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
