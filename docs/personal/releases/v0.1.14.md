# ELogSync Personal v0.1.14

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.14-windows-x64-setup.exe`
- **SHA-256**: `A7C9ABB5B7A90736B4B0CA386B05EC4AA2D373370159DCB3D6B0C86C4E32FAB6`
- The installer uses per-user installation and does not require administrator privileges. Close ELogSync before installing or upgrading.

### Highlights

- Fixed the shared confirmation dialog so its common heading, Cancel action, and processing state follow the active interface language.
- Completed the Backup & Restore audit: delete and restore confirmations now remain English in the English interface, while Chinese keeps its existing display.
- Backup timestamps and file sizes now use centralized locale-aware formatting. Backup and restore failures now use stable local error codes instead of backend message text.

### Data and limitations

- **Local data format version: 76**, unchanged from v0.1.13; no database schema upgrade is performed. Version 76 installations can upgrade directly.
- Existing business records, backup files, attachments, user input, and local configuration remain unchanged.
- Only a Windows x64 NSIS installer is provided; MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.14-windows-x64-setup.exe`
- **SHA-256**：`A7C9ABB5B7A90736B4B0CA386B05EC4AA2D373370159DCB3D6B0C86C4E32FAB6`
- 安装器采用当前用户模式，不要求管理员权限。安装或升级前请关闭正在运行的一录清。

### 本版内容

- 修复共享确认弹窗：通用标题、取消操作和处理中状态会跟随当前界面语言。
- 完成备份与恢复页面审计：英文界面的删除与恢复确认不再遗留中文，中文保持原有显示。
- 备份时间和文件大小改用集中式、随语言变化的格式化；备份与恢复失败提示改为稳定的本地化错误码，不再直接显示后端消息文本。

### 数据与限制

- **本机数据格式版本：76**，与 v0.1.13 相同，不执行数据库结构升级；数据格式为 76 的安装可直接升级。
- 本版不改变已有业务记录、备份文件、附件、用户输入或本机配置。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
