# ELogSync Personal v0.1.21

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.21-windows-x64-setup.exe`
- **SHA-256**: `D130FA0F7454FB7C3F7682F94F29B0596A424441D01C6EDC987A99B8B72A7B63` (33289213 bytes).
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing; the installer checks the desktop process and local service before replacing files.

### Highlights

- Sample and order fulfillment forms use consistent sections. Detail pages show read-only facts as text and include a separate fulfillment feedback section; order items appear immediately after fulfillment creation.
- Receipt pages consistently use allocation terminology in Simplified Chinese and English; customer receivable attachments upload correctly.
- Administrative divisions, industry classifications and currencies support dependency-aware deletion and working enable/disable actions. Hierarchical actions explain the affected item and applicable rule.
- Administrative division and industry XLSX imports identify one root from the file independently of the current selection, reject the wrong file type, show existing/imported values for matching codes, and report success or failure. Failed writes roll back the entire batch. Exports contain the selected country or top-level industry and its descendants.
- Currency selectors consistently support search and scrolling. The standard currency order is CNY, USD, EUR, TRY, VND, THB, IDR, HKD, MYR, SGD, INR, PHP, AED, JPY and KRW.
- After an AI organizer candidate is linked to an existing customer or supplier, dependent contacts, opportunities and next steps receive the confirmed relationship.
- Customer and supplier import templates group region references into separate country worksheets in both languages; failed prechecks visibly disable import confirmation.
- The About page shows updated product/contact information; company and product links open in the system default browser while ELogSync remains open.

### Data and limitations

- **Local data format version: 90. Database schema upgrade: Yes (89 -> 90).** Install over format 89 (v0.1.20); existing format 90 test installations can upgrade without a database migration.
- For older formats, first install the required intermediate schema-upgrade releases in order (for example, format 87 requires v0.1.20 before v0.1.21). Create a full local backup before upgrading.
- Bundled currencies are updated by code, retaining existing IDs, references and enable/disable state; missing currencies are inserted. Custom currencies outside the bundled set are preserved.
- Application-version gaps do not matter when the data format is unchanged. Existing records, attachments, user input and local configuration are preserved.
- Only a Windows x64 NSIS installer is provided. MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.21-windows-x64-setup.exe`
- **SHA-256**：`D130FA0F7454FB7C3F7682F94F29B0596A424441D01C6EDC987A99B8B72A7B63`（33289213 字节）。
- 安装器为当前用户模式 Windows x64 NSIS 安装包。安装前请关闭一录清；安装器会在替换文件前检查桌面主程序和本机服务。

### 本版内容

- 样件和订单履约编辑页统一分组；查看页以纯文本显示只读事实，并独立展示履约反馈；订单履约创建后立即显示履约项。
- 收款页面的中英文文案统一使用分配表述，修复客户欠款附件上传问题。
- 行政区划、行业分类和币种支持检查依赖后删除，修复停用与恢复操作；层级操作提示明确显示当前内容项及适用规则。
- 行政区划和行业分类 XLSX 导入从文件识别单个根节点，不依赖页面当前选择；拒绝类型不匹配的文件，预检展示同代码的导入数据与已有数据对比，导入结束后弹窗告知结果，写入失败整批回滚。导出包含所选国家或一级行业及其下级内容。
- 币种选择统一支持搜索与滚动，标准排序为 CNY、USD、EUR、TRY、VND、THB、IDR、HKD、MYR、SGD、INR、PHP、AED、JPY、KRW。
- AI 整理关联已有客户或供应商后，联系人、商机和下一步候选自动带入确认后的实际主体关系。
- 客户和供应商导入模板的地区参考按国家拆分工作表，中英文均适用；预检失败时确认导入按钮明确禁用。
- 关于页面更新产品与联系信息；公司网站和产品入口调用系统默认浏览器打开，ELogSync 窗口保持不变。

### 数据与限制

- **本机数据格式版本：90，数据库结构升级：有（89 -> 90）。** 可从格式 89（v0.1.20）升级；已经使用格式 90 的测试版可直接升级，不执行数据库迁移。
- 更旧的数据格式需先依次安装必要的结构升级中间版本，例如格式 87 需先安装 v0.1.20，再安装 v0.1.21。升级前请创建完整本机备份。
- 安装包中的币种按代码更新，保留已有 ID、业务引用和启停状态，不存在则新增；不在内置清单中的自定义币种保留。
- 应用版本号不连续但数据格式未变化时可以直接跨版本升级。已有业务记录、附件、用户输入和本机配置会被保留。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
