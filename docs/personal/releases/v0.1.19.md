# ELogSync Personal v0.1.19

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.19-windows-x64-setup.exe`
- **SHA-256**: `92FA8005D62152996DF4C73FD30CFA31B65D5B038CCE4052D5D9AA60BB229170`
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing; the installer checks the desktop process and local service before replacing files.

### Highlights

- Completed and cancelled follow-ups no longer participate in reminder or current-overdue handling.
- Preserved the original reminder timestamp and lifecycle history for completed and cancelled follow-ups.
- Kept the Personal desktop release aligned across the formal home and follow-up workspaces.

### Data and limitations

- **Local data format version: 76**, unchanged. Existing version 76 installations can upgrade directly without a database migration.
- Existing records, attachments, user input, reminder history and local configuration are preserved.
- Only a Windows x64 NSIS installer is provided. MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.19-windows-x64-setup.exe`
- **SHA-256**：`92FA8005D62152996DF4C73FD30CFA31B65D5B038CCE4052D5D9AA60BB229170`
- 安装器为当前用户模式 Windows x64 NSIS 安装包。安装前请关闭一录清；安装器会在替换文件前检查桌面主程序和本机服务。

### 本版内容

- 已完成或已取消的下一步不再参与提醒和当前逾期处理。
- 保留已完成、已取消下一步的原提醒时间和状态历史，便于历史查看。
- 首页待推进和下一步管理页统一执行相同的 Personal 状态规则。

### 数据与限制

- **本机数据格式版本：76**，保持不变；数据格式为 76 的现有安装可直接升级，不执行数据库迁移。
- 保留已有业务记录、附件、用户输入、提醒历史和本机配置。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
