# ELogSync Personal v0.1.11

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.11-windows-x64-setup.exe`
- **SHA-256**: `47CA98EE5C9B735BA5B80240039414DC92D339F16B75D2C5111696E82FBF7711`
- The installer uses per-user installation and does not require administrator privileges. Close ELogSync before installing or upgrading.

### Highlights

- Fixed inability to enter or edit opportunity fields in the English interface.
- Added a unified i18n maintenance guide covering semantic keys, shared modules, stable field identifiers, and future language additions.
- Updated opportunity and license structure gates to recognize migrated i18n resources instead of legacy Chinese copy.
- This release enters maintenance freeze; no further feature or routine optimization work is planned for now.

### Data and limitations

- **Local data format version: 76**, unchanged from v0.1.10; no database schema upgrade.
- Existing business records, attachments, user input, and AI candidate text are unchanged.
- Only a Windows x64 NSIS installer is provided; MSI and macOS installers are not published.
- Full system page-by-page i18n migration is not complete; unmigrated areas continue using the compatibility layer.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.11-windows-x64-setup.exe`

- **本机数据格式版本：76**，与 v0.1.10 相同，无数据库结构升级。

- 尚未完成全系统 i18n 逐页迁移；未迁移区域继续使用兼容层。
