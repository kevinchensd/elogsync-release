# ELogSync Personal v0.1.22

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.22-windows-x64-setup.exe`
- **SHA-256**: `2678E83761ABB880518CB6F326C304FD85B557F95646B291604B2187B2D02605` (33286415 bytes).
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing. Create a full local backup before upgrading.

### Highlights

- Online activation shows a waiting dialog and prevents repeat clicks. The local service waits up to 20 seconds for activation, then uses the remaining time within a 30-second budget to verify an uncertain result. The interface has a total 35-second limit and gives a clear timeout message instead of waiting indefinitely.
- When the activation response is lost but authorization has succeeded, the application confirms the status and updates the page without requiring a restart. Unconfirmed results and explicit rejections are not shown as success.
- An activated instance shows “Already activated. No further activation is needed.” and hides the activation-code input and button. The local service also returns the existing active status before processing a duplicate submission, without sending or consuming the newly entered code.
- Activation rejection, service unavailability, timeout and local-save failure have specific Simplified Chinese and English messages.

### Data and limitations

- **Local data format version: 90. Database schema upgrade: No (90 -> 90).** Install directly over v0.1.21 or another format-90 installation; no database migration is performed.
- Older data formats must first upgrade through the required schema-upgrade releases. For format 89, install v0.1.21 before v0.1.22.
- Existing business records, attachments and local configuration are preserved. This release does not change the database schema.
- Only a Windows x64 NSIS installer is provided. MSI and macOS installers are not published.

## 简体中文

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.22-windows-x64-setup.exe`
- **SHA-256**：`2678E83761ABB880518CB6F326C304FD85B557F95646B291604B2187B2D02605`（33286415 字节）。
- 安装器为当前用户模式 Windows x64 NSIS 安装包。安装前请关闭一录清，升级前请创建完整本机备份。

### 本版内容

- 联网激活时显示等待窗口并阻止重复点击。本机服务最多等待激活反馈 20 秒，结果不确定时在总计 30 秒内使用剩余时间核验状态；界面总等待上限为 35 秒，超时后明确提示，不会无限等待。
- 激活响应丢失但授权实际成功时，应用会核实状态并更新页面，无需重启；尚未确认的结果和明确拒绝不会显示为成功。
- 已激活的实例显示“已激活，无需再次激活”，隐藏激活码输入框和按钮；后端在处理重复提交前直接返回现有激活状态，不发送或消耗新输入的激活码。
- 激活码被拒绝、服务暂不可用、超时和本机保存失败均提供明确的中英文提示。

### 数据与限制

- **本机数据格式版本：90，数据库结构升级：无（90 -> 90）。** 可从 v0.1.21 或其他格式 90 的安装直接升级，不执行数据库迁移。
- 更旧的数据格式需先依次安装必要的结构升级中间版本；格式 89 请先安装 v0.1.21，再安装 v0.1.22。
- 已有业务记录、附件和本机配置会被保留。本版不修改数据库结构。
- 仅提供 Windows x64 NSIS 安装器；MSI 和 macOS 安装器未发布。
