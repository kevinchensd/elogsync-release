# ELogSync Personal v0.1.24 — stable release / 正式版

## English

This is the published stable release. The installer version is **0.1.24**.

### Release scope

- Unifies Chinese and English module names, field labels, helper text and export labels, including the approved settings card hierarchy.
- Adds **Import from Supplier Quote** to order creation. Copy items, currency and terms once, choose a customer, then save a pending-confirmation sales order. The order and quote remain independent.
- Corrects the order detail source label and Shark shortcut for supplier imports. Sales-source orders keep opening their actual sales quote even when they have extra supplier quote links.
- Aligns order overview and list values with their labels: order date, number, currency, total amount and status now use the corresponding order fields in Chinese and English.
- Restores receipt detail labels and receipt date visibility, adds clear required-field markers and validation feedback, and keeps long correction dialogs scrollable within the viewport.
- Retains existing import field identifiers and compatibility with previously supported customer/supplier templates.

### Data and installer

- Windows x64 NSIS current-user installer: `ELogSync-Personal-v0.1.24-windows-x64-setup.exe`.
- **Local data format version: 90. Database schema upgrade: No (90 -> 90).** Existing format-90 installations can upgrade directly; older data formats still follow the documented intermediate-version requirements.
- The corrected Indonesia XLSX is delivered separately under `reference-data/administrative-divisions`; installation does not import optional country files or overwrite existing administrative options.
- SHA-256: `133BD3E76B6B5B57D212E94417F43FEA432A993434E89633D1C13131F12B0DDC`.
- Build and verification completed before publication. The source tag is `v0.1.24` and the public download is the `personal-v0.1.24` GitHub Release.

## 简体中文

这是已完成验收并正式发布的版本，安装器版本为 **0.1.24**。

### 发布内容

- 统一中文、英文模块名称、字段标签、辅助说明和导出显示名称，应用已确认的设置卡片层级。
- 订单增加“从供应商报价导入”：一次性复用明细、币种和条款，选择客户后保存为待确认销售订单；订单与原报价独立维护。
- 修正供应商导入订单的详情来源标签和小鲨鱼快捷入口；销售来源订单即使额外关联供应商报价，仍准确打开实际来源销售报价。
- 修正订单概览和列表的字段对应关系；中英文下的订单日期、编号、币种、总金额和状态均显示对应订单字段。
- 恢复收款详情字段标题和收款日期显示，增加明确的必填字段标记与校验提示，并让内容较多的更正弹窗在视口内滚动。
- 保留原有导入字段标识，以及已支持的旧版客户、供应商导入模板兼容性。

### 数据与安装器

- Windows x64 NSIS 当前用户安装器：`ELogSync-Personal-v0.1.24-windows-x64-setup.exe`。
- **本机数据格式版本：90，数据库结构升级：无（90 -> 90）。** 格式 90 的已有安装可直接升级；更早数据格式仍须遵循已记录的中间版本升级要求。
- 修正后的印尼 XLSX 在 `reference-data/administrative-divisions` 单独交付；安装程序不会自动导入可选国家文件，也不覆盖已有行政区划选项。
- SHA-256：`133BD3E76B6B5B57D212E94417F43FEA432A993434E89633D1C13131F12B0DDC`。
- 构建和验证已在发布前完成；源码标签为 `v0.1.24`，公开下载入口为 `personal-v0.1.24` GitHub Release。
