# ELogSync Personal v0.1.18

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.18-windows-x64-setup.exe`
- **SHA-256**: `7809E2B1B64C5A1E65ABA9722AE290505D2E9C6A0D2828D9224CBD75CE705383`
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing; the installer checks the desktop process and local service before replacing files.

### Highlights

- Completed the personal business workflow coverage for quick notes, AI organizer review, quotations, orders, fulfillment, receipts and deletion-impact checks.
- Improved duplicate review, confirmation feedback, attachment handling and desktop workflow consistency.
- Continued English and Simplified Chinese UI coverage across the released workflows.

### Data and limitations

- **Local data format version: 76**, unchanged. Existing version 76 installations can upgrade directly without a database migration.
- Existing records, attachments, user input, AI candidate text and local configuration are preserved.
- Only a Windows x64 NSIS installer is provided. MSI and macOS installers are not published.
