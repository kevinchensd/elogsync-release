# ELogSync Personal v0.1.9

## 简体中文

### 下载与安装

- **Windows x64 NSIS 安装器**：`ELogSync-Personal-v0.1.9-windows-x64-setup.exe`
- SHA-256：`A3FE6A883877D4D3D3731A6E2777CEDA3F72C9316D5E818BFDD36A7457E7C480`
- 安装器采用“当前用户”模式，不要求管理员权限。请先关闭正在运行的一录清，再运行安装器完成安装或升级。

### 本版内容

- 完善英文界面的固定文案：供应商报价、客户报价、订单列表及其筛选和导出窗口、备份与恢复、AI 助手均不再混入中文固定文案。
- 英文界面的业务参考数据与固定选项显示英文名称；既有业务记录仍保留原始输入内容。
- 授权与实例页面不再显示无须用户操作的“自动授权检查”板块；后台仍每 7 天自动检查授权状态。

### 数据与更新提醒

- 升级前建议在“系统配置 → 备份与恢复”创建完整备份。
- 本版仅提供 Windows x64 NSIS 安装器；macOS、MSI 安装器尚未发布。
- 请勿将数据库、附件目录、API Key 或授权配置上传到公开仓库或 Release。

## English

### Download and install

- **Windows x64 NSIS installer**: `ELogSync-Personal-v0.1.9-windows-x64-setup.exe`
- SHA-256: `A3FE6A883877D4D3D3731A6E2777CEDA3F72C9316D5E818BFDD36A7457E7C480`
- The installer is per-user and does not require administrator privileges. Close ELogSync before installing or updating.

### Highlights

- Completed English fixed-copy coverage for supplier quotes, customer quotes, order lists and their filter/export dialogs, Backup & Restore, and AI Assistant.
- Reference data and fixed options now display English names in the English interface; existing business records retain their original entered values.
- The License & Instance page no longer displays the non-actionable automatic authorization review panel. Background authorization checking continues every seven days.

### Data and update notes

- Create a full backup from **System Settings → Backup & Restore** before upgrading.
- This release provides only a Windows x64 NSIS installer. macOS and MSI installers are not published yet.
- Never upload databases, attachment folders, API keys, or license configuration to a public repository or Release.
