# ELogSync Personal v0.1.23

## English

### Download and install

- **Windows x64 installer**: `ELogSync-Personal-v0.1.23-windows-x64-setup.exe`
- **SHA-256**: A8FABC5BC0E0F1D25783BCD61DA873F3F4CE9C0355008035F6C5E1F4EB871649 (33284560 bytes).
- The installer is a per-user Windows x64 NSIS package. Close ELogSync before installing and create a full local backup.

### Highlights

- Keeps the activation-code input and “Verify online and activate” button visible in every license state.
- If the local instance is already active, clicking the button shows “Already activated. No further activation is needed.” as a popup and does not send or consume a new activation code.
- Retains the finite waiting dialog, lost-response recovery and specific activation timeout, rejection and local-save error messages introduced in v0.1.22.

### Data and limitations

- **Local data format version: 90. Database schema upgrade: No (90 -> 90).** Install directly over v0.1.22 or another format-90 installation; no database migration is performed.
- Existing business records, attachments and local configuration are preserved. Only a Windows x64 NSIS installer is provided.

### 下载与安装

- **Windows x64 安装器**：`ELogSync-Personal-v0.1.23-windows-x64-setup.exe`

- 无论当前授权状态如何，始终保留激活码输入框和“联网验证并激活”按钮。

### 数据与限制

- **本机数据格式版本：90，数据库结构升级：无（90 -> 90）。** 可直接从 v0.1.22 或其他格式 90 的安装升级，不执行数据库迁移。
- 已有业务记录、附件和本机配置会被保留。仅提供 Windows x64 NSIS 安装器。
