# Administrative division data / 国家行政区划数据

## English

Download the country-specific XLSX file you need, then import it from **Settings -> Business options -> Administrative divisions**. Complete the preview before confirming. Each file contains one country and uses the supported columns `code`, `parent_code`, `level`, `name_zh_cn`, `name_en`, `sort_order`, and `status`.

The current Personal scope is **country -> province/state -> city**. The files include the complete first-level list and the major cities needed by the current address selector; they are not a promise of every lower-level administrative unit.

Each country has one current XLSX file. Updates replace the same filename and download link; dated, versioned, and backup copies are not listed separately.

See the [download list](download-list.md) for file sizes, row counts, SHA-256 values, and direct downloads. Last generated: 2026-10-18.

## 简体中文

下载所需国家的 XLSX 文件，然后在 **设置 -> 业务选项 -> 行政区划** 中导入。确认导入前请先完成预检。每个文件只包含一个国家，使用当前支持的列：`code`、`parent_code`、`level`、`name_zh_cn`、`name_en`、`sort_order`、`status`。

当前个人版范围为“国家 -> 省/州 -> 城市”。文件包含完整的一级行政区划列表和当前地址选择所需的主要城市，不承诺覆盖所有更低层级行政区划。

每个国家只提供一份当前 XLSX 文件。更新时直接替换同名文件，下载链接不变，不另列带日期、版本号或备份后缀的副本。

请查看[下载列表](download-list.md)中的文件大小、数据行数、SHA-256 和直接下载链接。最后生成日期：2026-10-18。
